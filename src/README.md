# Forecasting application source

Python modules for sample-data generation, time-series features, model training, FastAPI inference and local monitoring helpers.

[Parent folder](../) · [Repository overview](../README.md) · [All projects](https://github.com/zahramardani/ML2PP-Artifacts/blob/main/PROJECTS.md)

## Contents

| Item | What it is |
|---|---|
| [api.py](api.py) | Forecasting request schema and FastAPI endpoints. |
| [features.py](features.py) | Forecasting feature definitions and chronological splitting. |
| [generate_data.py](generate_data.py) | Creates the synthetic hourly forecasting dataset. |
| [monitor.py](monitor.py) | Local missingness, mean-shift and forecast-error helpers. |
| [train.py](train.py) | Trains the XGBoost demonstration and writes model, metrics and reference statistics. |

**Start here:** [api.py](api.py).
